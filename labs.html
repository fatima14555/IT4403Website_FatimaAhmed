Modified Calculator Example

This part of Lab 2 focused on enhancing a calculator application using the jQuery library. This application converts the original JavaScript to jQuery, it has user input for numbers, allows the calculation type to be selected, and enables the user to choose a color for the results.

Lab 2- Part 2

Picture Browser Application

This part of Lab 2 is a slideshow of five images chosen from the Unsplash website. It is built using JavaScript and jQuery. The images are stored in an array and are displayed using fade transitions, captions, keyboard navigation, and an automatic slideshow that can be paused and resumed.

Book JSON

Lab 3 focused on how JSON values can be stored and displayed using jQuery/ JavaScript. In part 3, book information was extracted from JSON objects, and then it was dynamically displayed on a webpage using jQuery and added CSS styling.

Weather JSON

Lab 3 part 4 reads the weather.json file and then displays the important information from there onto a webpage. The temperature was originally in Kelvin, but it was converted to Fahrenheit and Celsius because that is more familiar. The data was extracted from structured JSON.
