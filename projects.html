IT 4403: Advanced Web and Mobile Application

Individual Milestone 1

Displaying JSON Data on Webpages

This first milestone required making two different webpages that read and display JSON data using JavaScript and jQuery. The first page uses a loop to read in different books and display them in a list. The second page reads in a single book and displays the full details in different sections.

Individual Milestone 2

Book Search and Bookshelf API Application

The second milestone required making a web application built with HTML, CSS, JavaScript, and jQuery that allows users to search for books using the Google Books API. Detailed information pages for each book are also included alongside a personalized bookshelf.

Individual Milestone 3

Book Search and My Collection SPA

The third milestone required making a single-page application built with HTML, CSS, JavaScript, and jQuery that dynamically searches the Google Books API for books. It has paginated results, with 10 results across 5 pages, showing 50 in total. Clicking the book shows the details below without requiring a page reload.

Link to the Book Search SPA

Individual Milestone 4

Book Search and My Library Collection SPA

The final milestone is an enhanced single-page application based on milestone 3, using jQuery and Mustache.js templates. It has a toggle grid and list views feature, tabbed navigation between search results and my library book collection, and dynamic book details loaded without any page reloads.
